# osu! Gacha Tower

Браузерная гача-RPG с реальными игроками osu! — **376 666 игроков** (osu!, taiko, catch, mania) с аватарками с osu.ppy.sh.

**Играть:** скачайте `index.html` и откройте в браузере (или включите GitHub Pages для этого репозитория).

## Возможности
- Гача с анимациями редкостей F → EX, ранги по популярности и pp, BP (Base Power)
- Команда из 5, 10 типов навыков и 10 пассивок, анимированные бои
- Башня на 150 этажей с 15 зонами, 6 данжей, 7 локаций
- Прокачка: уровни, навыки, пробуждение, повышение ранга, тренировка, моды
- Задания, достижения, награды за уровни, «Забрать все»
- Индекс всех игроков, сохранение в браузере, экспорт/импорт

## Сборка
```bash
python3 tools/inject5.py      # src/game.template.html + data/ → index.html
node tests/t5.js              # проверка (Playwright)
```
Подробности для разработки — в `CLAUDE.md`.

Фан-проект, не связан с ppy Pty Ltd. Данные игроков — с osu.ppy.sh.
